# DB Autodetailing — alternativní autorský koncept

Výrazně odlišný vizuální návrh pro DB Autodetailing: tmavý editorial design, velkoformátové fotografie, typografická prezentace služeb a asymetrická galerie.

## Stránky
- `index.html` — úvod, realizace, služby a fotogalerie
- `sluzby.html` — kompletní přehled 12 služeb
- `keramika.html` — keramické povlaky a renovace kůže
- `o-nas.html` — představení studia
- `kontakt.html` — telefon, e-mail, dostupnost a Google Mapy

## Technologie
Statické HTML, CSS a JavaScript bez frameworku. Responzivní navigace, galerie s lightboxem, Google Maps iframe. Fotografie v `fotografie/`; původní ilustrační SVG soubory jsou ponechány v `galerie/` jako nepoužívané podklady.

## Publikování
Nahrajte obsah ZIPu přímo do kořene repozitáře GitHub Pages. `index.html` musí být v kořeni. Pro tuto alternativní variantu je vhodné použít samostatný repozitář, aby se nepřepsala předchozí verze.

## Upozornění
Jde o **neoficiální návrh**, který není provozován ani schválen společností DB Autodetailing. Kontaktní údaje a texty vycházejí z dřívější verze návrhu; před předáním klientovi ověřte aktuálnost. Fotografie použijte veřejně jen s oprávněním držitele práv. Poloha na mapě je orientační a je vhodné ji před návštěvou potvrdit.
